# HUMBLE Carousel Website v4

React + Vite landing page for HUMBLE Carousel 1.0.3.

## Included
- Actual HUMBLE Carousel 1.0.3 ZIP
- Muted looping Carousel preview video
- 10 real style preview images
- Magnetic dock navigation
- Letter Cascade hero
- Scroll-based HUMBLE logo velocity strip
- Interactive flip-stack style showcase
- Smooth reveal animations
- Visitor card that counts once per browser session (refresh does not increment)
- Click sound via Web Audio
- After Effects compatibility inside installation section
- GitHub Pages workflow
- Original HUMBLE social links

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub Pages
Push the project to a GitHub repository with the included workflow. Enable GitHub Pages using **GitHub Actions** as the source.
